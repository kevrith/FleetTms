# Legal drafts

DRAFT documents for review by a Kenyan advocate familiar with data protection before any public
launch. They are planning drafts, not legal advice. The app currently shows version `draft-1` of each
document and records who accepted which version (see `PolicyAcceptance` in the API).

When a document changes, bump its version in `apps/api/app/config.py`; everyone then has to accept again.

| Document | File | Who accepts it |
|---|---|---|
| Terms of Service | [terms-of-service.md](terms-of-service.md) | Every user |
| Privacy Policy | [privacy-policy.md](privacy-policy.md) | Every user |
| Data Processing Agreement | [data-processing-agreement.md](data-processing-agreement.md) | The business owner at sign-up |
| Driver monitoring notice | [monitoring-notice.md](monitoring-notice.md) | Drivers and turnboys at first sign-in |
